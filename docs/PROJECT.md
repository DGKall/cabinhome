# 项目简要

更新：2026-10-18。工作名 Cabin Game，正式名称未定。

## 目标与方向

以北侧近山、南侧开阔草甸和场外湖面/雪山为背景，制作可逐步升级的小屋场景。氛围为休闲、治愈、静谧、植物鲜活。建造、布置与生活互动是候选玩法方向，具体循环尚未定稿。

用户已选 009 梦核简化：自然房屋比例、哑光大色块、克制细节、成组草花与明显留白。004 阿勒泰花甸、006 梦核草坡为辅助参考。

技术路线：Unity 6.3 LTS（6000.3.26f1）+ URP + C#；Blender 5.2 LTS；混元 3D 网页版辅助道具。macOS 优先开发与试玩，Windows 和 iOS 为目标平台，具体最低设备、帧率和画质档位待实测确定。

## 首个交付：可在 Mac 试玩的空间灰盒

- 米制地形、初始小屋、门口和步道，以及后续扩建/功能区包络。
- 临时观察/移动控制，便于在 Mac 检查比例；最终游戏相机和角色方案尚未确定。
- 四组固定评审镜头，使用同一套几何；它们不是最终游戏相机模式。
- 少量共享材质和代表性道具验证美术方向及导入流程。

首轮不实现完整家具库、角色系统、天气模拟、种植、建筑经济、联机和全部扩建内容。

## 暂定尺寸

| 内容 | 灰盒基线 |
|---|---|
| 活动范围 | 160×120 m |
| 连续升级台地 | 64×48 m，南北高差 0.60 m |
| 主屋阶段 1 / 2 / 3 | 6×8 / 10×12 / 16×12 m，累计占地 48 / 120 / 192 m² |
| 主屋固定西南角 | 规划 (72,58)，完成地坪标高 101 |
| 最终北墙至山脚 | 16 m |

完整地形公式、边界和相机坐标见设计简报。Unity 坐标采用 X 东、Y 上、Z 北，规划 P 映射为 U=(P.x,P.z-99,P.y)。这是当前实施约定，先用一米基准物与南北标记核验。模型导入轴向由导出/导入链路单独验证。

以上尺寸可用于可逆灰盒，未经试玩与用户评审不得写成最终规格。
