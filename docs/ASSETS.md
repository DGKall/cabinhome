## PRP_001 混元提示词示例

> 单个用于风格化治愈系草甸游戏的圆钝不规则石块，整体简洁，轮廓自然，灰蓝与浅灰暖色，哑光大色块，少量宽大的表面转折，没有细密裂纹，没有写实扫描质感。独立完整物体，无底座、无地面、无草、无花、无文字；底部略平，适合放置在草地边缘。保持简化游戏道具风格。

提示词不保证生成模型的拓扑/面数。先保留生成原件，再在 Blender 中检查和处理。处理后石块可先以 100–500 三角面、1 材质作为原型目标；无法保持轮廓时记录实际统计，不硬凑面数。

## 你需要交给开发侧的内容

1. 原始 GLB（若网页版支持），连同贴图；可附一张预览图。若只能导出 FBX/OBJ，保留配套贴图并说明。
2. 来源链接或平台名、生成提示词/参数、日期；购买或下载的资产附许可说明，标明商业使用与修改范围。不要提交账号凭据。
3. 放到 `assets-source/hunyuan/inbox/PRP_001/`，或提供实际文件位置。收件箱仅本地保留，整理后再纳入版本管理。

## 开发侧整理与验收

- 在 `assets-source/blender/` 保存可编辑 `.blend`；处理后模型/贴图放 `assets-source/exports/资产ID/`。
- 核对单位（米）、底部中心原点、缩放/朝向、法线、UV、缺失贴图、三角面数、材质数。生成资产需要减面或重拓扑时先处理。
- Unity 先用 FBX 导入；GLB 需在工程安装并验证 glTFast 后使用。不要把复杂 Blender 节点效果当成可自动迁移的 URP 材质。
- 场景只放整理过的资产副本，保存 `.meta`；不将高模下载文件直接塞进 Assets。
- 提交资产前记录下表并确认许可允许当前用途；外部资产受各自许可约束，私有 Git 仓库不等于获得再分发许可。
