## 下一步（给接手 agent）

2026-10-21 评估后的建议：若用户决定推进本轮 2D 构思，先定义“营地前三天”的可逆切片，验证摆放、工作队列、寻路、遮挡与存读档，再尽早做 Windows/iOS 实机验证。此项是建议，尚未获实现授权；先明确它与当前 3D 工程的关系，不能自动将旧场景改成新方案。以下仍为现有 3D 工程的未完成事项。

先收集用户对 `019` 外观的具体修改点，再调整体量、屋顶、门窗与露台。用户已明确本轮先只看外观，室内和阁楼通行稍后再做；019 尚未通过评审，5×7 m 与现有 6×8 m 都未被选为新方案尺寸。对照 009，开发侧建议减少木纹和装饰、突出门窗与屋顶比例，此建议尚未获确认。外观方向接受后统一各外观视图与建模参数；室内暂缓，但外壳须保留后续布置的调整余地。当前不替换 Unity 小屋或改变原升级基线。

先让用户试玩根目录 `play-style-demo.command`，查看 `Builds/style-review/` 四视角。收集树冠规则感、草花密度、色调与北侧山坡体量意见，再修改 `Assets/LocalArt/Style009.unity`。当前不用继续生成素材或扩展玩法。

阅读 STYLE-VALIDATION、ASSETS 与 `development/art/README.md`。本机树石/场景保存在 Git 忽略目录；配方、统计、代码与交接记录可从仓库获取。新的机器必须另行取得原始两个 GLB 才能重建风格版，不能把只有 Git 代码误认为全部美术文件已同步。待归档网页版输出条款与实际生成输入后决定公开资产归档；不阻塞本机开发。
